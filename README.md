# 🏪 Zegowska-szama

Strona internetowa sklepiku szkolnego do zamawiania szamy i przeglądania produktów.
Pozwala na przeglądanie złożonych zamówień oraz promocji

## ✨ Funkcje

- logowanie użytkowników
- składanie zamówień
- zarządzanie stroną (admin)
- przeglądanie dostępnych produktów
- dodawanie produktów do koszyka
- podgląd zamówień i statusu zamówienia

## ⚙️ Instalacja
Pobierz repozytorium lub sklonuj je:
git clone https://github.com/Nyakosuki/Zegowska-szama.git

Umieść pliki w folderze hostingu (np. htdocs)
Uruchom lokalny hosting

Wyszukaj adres (np. localhost/zegowska-szama)

## 🛠️ Technologie

- PHP
- JavaScript
- Bootstrap
- MySQL

## 🧪 Środowisko

- System operacyjny: Windows 10/11
